# 长夜守望者

《长夜守望者》是一款 **俯视角动作生存肉鸽**。你扮演巡夜人，提着灯、带着剑，沿旧烽火道走向极北。黄昏搜集物资和修缮遗迹，深夜亲自迎击怪潮，黎明把一个字母改写成一条新的誓言。当前 Godot 试玩版本为 **0.9.2**。

## 世界观

远古巨神在混战中陨落。岁月把他们的骸骨埋进山谷、峡谷和水湾，巨剑成了山径的界碑，断肋成了峡谷的一道道门。后来的人在这些遗迹旁立起烽火，用一站接一站的火光维系大陆南北。

永夜和腐化从极北山口南侵，沿途的烽火相继熄灭。巡夜人从西南的陨王遗谷出发，在遗迹间重燃火种，穿过苔沼、风蚀古台和被树根绞住的环堡，最终登上黑曜长墙，迎战永夜先驱。遗迹里的铭文仍然能改写法则，每一次守到黎明，巡夜人都有机会刻下一条新誓。

| 区域 | 地标与地形 | 守夜时的变化 |
| --- | --- | --- |
| **陨王遗谷** | 沼泽苔原。戴冠陨王的头骨、胸廓和锈剑横卧谷中 | 泥潭减慢地面移动。夜间的苔雾会缩小光照范围，可以在陨王左眼架起骨弩 |
| **蚀沙古台** | 风蚀峡谷。断崖石阶通向砂岩高台，风白巨肋半埋在沙中 | 高台让骨弩射得更远。沙暴会吹熄暴露的火盆，附近的路障可以挡风 |
| **枯木环堡** | 巨树盘根围住水湾里的环形石堡，两座吊桥连接外岸 | 用机关切换升起的吊桥，改变地面敌人的来路。桥面上有人或地面敌人时，机关暂时无法起桥 |
| **黑曜长墙** | 极北雪壁。城墙守住山口，城外露出裂颅和青绿晶簇 | 风雪让篝火衰减加快。晶簇会强化附近敌人，可以用剑或骨弩摧毁 |

## 一局怎么玩

1. **大陆选路**。从行图上的金环节点出发。守夜和精英守夜是战斗，营地可补火或升级工事蓝图，祭坛可铸誓，夜话奇遇会影响下一场。输入同一个种子可以重走同一轮路线。
2. **黄昏准备**。每个战斗节点要守两夜，每夜前有 58 秒准备时间。去附近拾取余烬和骨材，给篝火添火，或靠近遗迹建造、升级对应位置的工事。准备好可以提前迎夜。
3. **深夜亲战**。挥剑、蓄力和冲刺处理来自不同方向的敌人。击杀积累夜战经验，升阶时可以强化剑、提灯、冲刺或生命。这些强化持续到本站战斗结束。倒计时结束后，仍要清完场上的敌人。
4. **黎明铸誓**。守完两夜后，在石碑上亲手替换一个发光的字母。首胜的例子是把 `SWORD` 的 `D` 改成 `E`，铸成 `SWORE`。以后挥剑命中时，附近的工事会短暂加速并提高暴击率。当前有 16 种誓言，可以围绕光照、近战、工事和资源组合。
5. **登上长墙**。击败永夜先驱后可以进入下一轮。路线重新生成、敌人加强，誓言、遗物和蓝图随巡夜人继续前进。

### 守夜的关键规则

- **篝火**会在深夜持续消耗，也会被敌人攻击。火弱时照亮的范围缩小。用余烬添火才能稳住防线，火势归零则本站失败，可以重试或回到行图。巡夜人的生命值单独计算，倒地会消耗余烬并退回篝火附近。
- **提灯**用灯油照亮前方。影潜者会在阴影中隐身，灯光可以让它显形。普通骨弩会锁定照亮的敌人，石墙和巨骨会截断光照。噬火蛾会找正在燃烧的光源，开关提灯也可以用来引开它。
- **工事**沿环境里的槽位建造，辅助近战守夜。烽火盆补足照明，骨弩台远射，誓言路障拖住地面敌人，火油槽可以减速和引燃。每张战场有八个与地形绑定的安装位，工事最高三级。
- **敌人的威胁各不相同**。爬尸结群压向篝火，影潜者从暗处接近，噬火蛾会扑灭火盆，掘骨巨尸擅长拆路障，灰烬咒术师会干扰工事。永夜先驱还会召怪、熄灭附近火盆。

### 操作

| 按键 | 操作 |
| --- | --- |
| WASD 或方向键、鼠标 | 移动、瞄准 |
| 左键／长按后松开 | 挥剑／蓄力重斩 |
| 空格或 J、Shift | 快速挥剑、冲刺 |
| E | 拾取补给、添火或打开遗迹工事菜单 |
| F、Q | 开关提灯、在篝火旁花费余烬治疗和补灯油 |
| Enter、Tab、Esc | 提前迎夜、查看来袭路线、关闭菜单或暂停 |
| R | 在枯木环堡的机关旁操作吊桥 |

行图可用滚轮或底部的加减号缩放，右键拖动，点击缩放比例恢复全图。战斗中悬停遗迹可查看工事的实际作用范围。

## 运行与协作

1. 安装 [Godot 4.7.2](https://godotengine.org/download/archive/4.7.2-stable/)。
2. 克隆仓库，在 Godot 项目管理器导入 [NightWatcher/project.godot](NightWatcher/project.godot)。等待首次导入完成后按 **F5**，主场景会直接打开大陆行图。
3. 如需试玩分发文件，在 Godot 安装同版本导出模板，从 **项目 → 导出** 选择 `macOS` 或 `Windows` 预设。两套工程可离线运行，使用 Compatibility 渲染。macOS 已实机验证，Windows x64 已完成导出校验。

| 想改什么 | 从哪里开始 |
| --- | --- |
| 行图节点、营地与剧情事件 | [scripts/campaign](NightWatcher/scripts/campaign) 里的 `Main.gd`、`Route.gd`、`WorldMap.gd` |
| 波次、地形规则、灯光与碰撞 | [scripts/battle](NightWatcher/scripts/battle) 里的 `BattleLevel.gd`、`BattleMaps.gd`、`WaveSpawner.gd`、`LightManager.gd`、`BattleCollision.gd` |
| 战斗数值、敌人和命中 | [scripts/entities/Combat.gd](NightWatcher/scripts/entities/Combat.gd) 与 [敌人控制器](NightWatcher/scripts/entities/EnemyController.gd) |
| 誓言效果、跨关资源和轮回 | [OathDatabase.gd](NightWatcher/scripts/autoload/OathDatabase.gd) 与 [RunState.gd](NightWatcher/scripts/autoload/RunState.gd) |
| 地标、角色动作与手绘效果 | [scripts/model](NightWatcher/scripts/model) 里的各区域模型、`CombatPuppets.gd` 和 `BattleImpact.gd)。图像、模型与字体来源见 [ART.md](ART.md) |
| HUD、夜战强化和铸誓界面 | [scenes/ui](NightWatcher/scenes/ui) |

想跟队友确认同一处问题，可以附上区域、昼夜阶段和行图种子。调整巨骨等地标时，安装位在 `BattleMaps.gd`，三维造型在区域的模型脚本中。换件后可用同机位截图配合碰撞测试，核对眼窝骨弩是否贴合、骨缝和来袭路线是否仍能通过。

从仓库根目录运行以下命令可复查主流程、碰撞和战斗。首次克隆需要先导入资源。

```sh
godot --headless --path NightWatcher --editor --import --quit
godot --headless --path NightWatcher --script res://tests/campaign_smoke.gd
godot --headless --path NightWatcher --script res://tests/collision_smoke.gd
godot --headless --path NightWatcher --script res://tests/impact_smoke.gd
```

当前战役进度保存在运行内存。陨王巨骨等关键地标还待高精度建模，现有头骨、胸廓和手臂可分件检查碰撞。

## 同仓库的《跨时空守望》

这是一个独立的监控解谜原型。玩家在机房里用终端读取档案，再用 CAM-08 观察雪夜永昌堡。先从 `LOG-041.txt` 核对年代线索，点击并剪除监控中不该存在的物件，随后在终端与守军取得联系。总时限为 180 秒，回应后还会并行计时 45 秒的清除时限。导入 [SpacetimeSentinel/project.godot](SpacetimeSentinel/project.godot) 可单独运行。
