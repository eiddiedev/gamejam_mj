# 长夜守望者

《长夜守望者》是一款 **俯视角动作生存肉鸽**。你扮演巡夜人，提着灯、带着剑，沿旧烽火道走向极北。黄昏搜集物资、添火和修缮遗迹，深夜亲自迎击怪潮，守过两夜后改写铭文，带着新的能力走向下一站。

## 世界观

远古巨神在混战中陨落。岁月把他们的骸骨埋进山谷、峡谷和水湾，巨剑成了山径的界碑，断肋成了峡谷的一道道门。后来的人在这些遗迹旁立起烽火，用一站接一站的火光维系大陆南北。

永夜和腐化从极北山口南侵，沿途的烽火相继熄灭。巡夜人从西南的陨王遗谷出发，在遗迹间重燃火种，穿过苔沼、风蚀古台和被树根绞住的环堡，最终登上黑曜长墙，迎战永夜先驱。遗迹里的旧铭文仍能改写法则，因此巡夜人走得越远，剑、火和沿途工事的用法也会随誓言改变。

| 区域 | 地标与地形 | 守夜时的变化 |
| --- | --- | --- |
| **陨王遗谷** | 沼泽苔原。戴冠陨王的头骨、胸廓和锈剑横卧谷中 | 泥潭减慢地面移动。夜间的苔雾会缩小光照范围，可以在陨王左眼架起骨弩 |
| **蚀沙古台** | 风蚀峡谷。断崖石阶通向砂岩高台，风白巨肋半埋在沙中 | 高台让骨弩射得更远。沙暴会吹熄暴露的火盆，附近的路障可以挡风 |
| **枯木环堡** | 巨树盘根围住水湾里的环形石堡，两座吊桥连接外岸 | 用机关切换升起的吊桥，改变地面敌人的来路。桥面上有人或地面敌人时，机关暂时无法起桥 |
| **黑曜长墙** | 极北雪壁。城墙守住山口，城外露出裂颅和青绿晶簇 | 风雪让篝火衰减加快。晶簇会强化附近敌人，可以用剑或骨弩摧毁 |

## 一局怎么玩

每站都要决定把有限的余烬花在哪里。添柴能稳住后续战斗，修缮遗迹里的工事能腾出手追击危险敌人，也可以把资源留给自己，靠挥剑、提灯和走位守完两夜。

1. **大陆选路**。从行图上的金环节点出发。守夜和精英守夜是战斗，余烬营地可补回 40 点起始火势或提升一种工事的初建等级，祭坛可铸誓，夜话奇遇会影响下一场。输入同一个种子可以重走同一轮路线。
2. **黄昏准备**。每个战斗节点要守两夜，每夜前有 58 秒准备时间。去附近拾取余烬和骨材，给篝火添火，或靠近遗迹建造、升级对应位置的工事。准备好可以提前迎夜。
3. **深夜亲战**。用挥剑、蓄力和冲刺应对不同来路的敌人。击杀积累夜战经验，升阶时从剑、提灯、冲刺或生命强化中选择。强化持续到本站战斗结束。每晚放完所有波次并清场后才会进入下一阶段，倒计时归零时也要清场。
4. **黎明铸誓**。守完两夜后，在石碑上亲手替换一个发光的字母。首胜刻的是 `SWORE`，由 `SWORD` 的 `D` 改成 `E`。以后挥剑命中时，附近的工事会短暂加速并提高暴击率。当前有 16 种誓言，可以围绕光照、近战、工事和资源组合。例如 `NEAR` 鼓励你离开火堆主动迎敌，`MIGHT` 让照到敌人的灯光变成持续伤害。
5. **登上长墙**。精英守夜可获得尚未收集的遗物，例如能在每场胜利后额外补火的守火铜环。击败永夜先驱后可以进入下一轮，面对更强的敌人。

| 进度 | 会保留什么 |
| --- | --- |
| 从第一夜到第二夜 | 已造的工事、夜战强化和剩余火势 |
| 从一站到下一站 | 余烬、骨材、誓言、蓝图和遗物。上场战斗剩余的火势会计入下一场的起始火势 |
| 进入下一轮永夜 | 誓言、蓝图、遗物与剩余材料。烽火复满，行图洗牌 |

### 守夜的关键规则

- **篝火**会在深夜持续消耗，也会被敌人攻击。火弱时照亮的范围缩小。用余烬添火才能稳住防线，火势归零则本站失败，可以重试或回到行图。巡夜人的生命值单独计算，倒地会消耗余烬并退回篝火附近。
- **提灯**用灯油照亮前方。影潜者会在阴影中隐身，灯光可以让它显形。骨弩只会对被照亮的敌人射击，石墙和巨骨会截断光照。噬火蛾会找正在燃烧的光源，开关提灯也可以用来引开它。
- **工事**是可选的战术辅助，每张战场有八个和遗迹结合的安装位。例如骨弩嵌进陨王的眼窝，火油槽利用老树下的洼地。烽火盆补足照明，骨弩台远射，誓言路障拖住地面敌人，火油槽可以减速和引燃。工事最高三级，夜间能修理、复燃或引燃现有工事。
- **敌人的威胁各不相同**。爬尸结群压向篝火，影潜者从暗处接近，噬火蛾会收翼俯冲撞向光源，掘骨巨尸擅长拆路障，灰烬咒术师会干扰工事。永夜先驱施法前会抬手，随后召来爬尸并熄灭附近的火盆。

### 操作

| 按键 | 操作 |
| --- | --- |
| WASD 或方向键、鼠标 | 移动、瞄准 |
| 左键／长按后松开 | 挥剑／蓄力重斩 |
| 空格或 J、Shift | 快速挥剑、冲刺 |
| E | 拾取补给、添火。黄昏打开工事菜单，深夜操作已有工事 |
| F、Q | 开关提灯、在篝火旁花费余烬治疗和补灯油 |
| Enter、Tab、Esc | 提前迎夜、查看来袭路线、关闭菜单或暂停 |
| R | 在枯木环堡的机关旁操作吊桥 |

行图可用滚轮或底部的加减号缩放，右键拖动，点击缩放比例恢复全图。按 Tab 选到画外节点时，行图会平移将它带回视野，侧栏也可点「回到所选」。战斗中悬停遗迹或打开工事菜单可查看作用范围。实线表示当前范围，虚线表示建成或升级后的范围。篝火受袭时火势印记会短暂变红，降到 25% 时会一直提示。

营地、夜话和轮回等界面可用 Tab 或 Shift+Tab 在选项间移动，Enter 确认。铸誓时先选石碑，再键入提示的字母或确认刻入。

## 运行与协作

1. 安装 [Godot 4.7.2](https://godotengine.org/download/archive/4.7.2-stable/)。
2. 克隆仓库，在 Godot 项目管理器导入 [NightWatcher/project.godot](NightWatcher/project.godot)。等待首次导入完成后按 **F5**，主场景会直接打开大陆行图。
3. 首次试玩从陨王遗谷开始。建议亲手守完两夜并铸成第一条誓言，再回行图看分岔。协作时可以用种子 `51618324` 复现同一条路线。
4. 如需试玩分发文件，在 Godot 安装同版本导出模板，从 **项目 → 导出** 选择 `macOS` 或 `Windows` 预设。两套工程可离线运行，使用 Compatibility 渲染。试玩包已经过 macOS 实机验证和 Windows x64 导出校验。

| 想改什么 | 从哪里开始 |
| --- | --- |
| 行图节点、营地与剧情事件 | [scripts/campaign](NightWatcher/scripts/campaign) 里的 `Main.gd`、`Route.gd`、`WorldMap.gd` |
| 波次、地形规则、灯光与碰撞 | [scripts/battle](NightWatcher/scripts/battle) 里的 `BattleLevel.gd`、`BattleMaps.gd`、`WaveSpawner.gd`、`LightManager.gd`、`BattleCollision.gd` |
| 战斗数值、敌人和命中 | [scripts/entities/Combat.gd](NightWatcher/scripts/entities/Combat.gd) 与 [敌人控制器](NightWatcher/scripts/entities/EnemyController.gd) |
| 誓言效果、跨关资源和轮回 | [OathDatabase.gd](NightWatcher/scripts/autoload/OathDatabase.gd) 与 [RunState.gd](NightWatcher/scripts/autoload/RunState.gd) |
| 地标、角色动作与手绘效果 | [scripts/model](NightWatcher/scripts/model) 里的各区域模型、`CombatPuppets.gd` 和 `BattleImpact.gd`。图像、模型与字体来源见 [ART.md](ART.md) |
| HUD、夜战强化和铸誓界面 | [scenes/ui](NightWatcher/scenes/ui) |

反馈战斗问题时附上区域、昼夜阶段和行图种子。调整巨骨等地标时，安装位在 `BattleMaps.gd`，陨王巨骨装配在 `FallenKing.gd`。换件后用同机位截图和碰撞测试核对眼窝骨弩、骨缝以及敌人来路。碰撞测试也会检查四区所有工事位是否能从出生点到达交互范围。

从仓库根目录运行以下命令可复查主流程、碰撞和战斗。首次克隆需要先导入资源。

```sh
godot --headless --path NightWatcher --editor --import --quit
godot --headless --path NightWatcher --script res://tests/campaign_smoke.gd
godot --headless --path NightWatcher --script res://tests/collision_smoke.gd
godot --headless --path NightWatcher --script res://tests/impact_smoke.gd
```

当前战役进度保存在运行内存。陨王遗谷已细化头骨、胸廓和手臂，并接入战场碰撞。头骨可从 GLB 单独编辑，胸廓和手臂各用一份 Godot 模型脚本。

## 同仓库的《跨时空守望》

这是一个独立的监控解谜原型。2026 年，一名档案员在旧数据中心打开了明代永昌堡的雪夜监控。一本历史档案能解释画面中大部分物件，可是守军突然开口，请求档案员阻止系统抹除他的信号。

先用 `LOG-041.txt` 核对地点和年代，从 CAM-08 剪除与史料冲突的物件，再用终端回应守军、锁定并保留他的信号。任务总时限为 180 秒，回应后还有一条并行的 45 秒清除倒计时。导入 [SpacetimeSentinel/project.godot](SpacetimeSentinel/project.godot) 可单独运行。
